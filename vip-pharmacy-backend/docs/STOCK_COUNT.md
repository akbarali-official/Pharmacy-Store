# Stock count (physical inventory)

Use a stock count to compare what is on the shelves with what the system says, and to correct differences with a full audit trail.

## Steps
1. *Stock Count* → **Start new count** (whole store, or one category). The system takes a snapshot of every batch that has stock.
2. Print the count sheet (blind mode hides the system quantity so counters are not influenced), count the shelves and type the counted quantity for each batch. Use **Save progress** as you go; unsaved changes are saved automatically every 20 seconds.
3. A manager clicks **Review differences** to see shortages and surpluses (units and value at cost).
4. **Complete & apply** (owner/manager only) adjusts stock for every counted batch whose quantity differs. Batches left uncounted are not changed. Every adjustment is recorded in the stock movements with the reason "Stock count #N".
5. Export the CSV or print the variance report for your records.

## Good practice
- Do not sell during a count if you can avoid it. If stock moves after the snapshot, the system refuses to apply a shortage that no longer fits and asks you to recount.
- Count one shelf or category at a time on busy days.
- Investigate large shortages before applying them; they may be unrecorded returns, theft or data-entry errors.
